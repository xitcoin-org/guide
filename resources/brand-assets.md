# Brand overview

Xitcoin's visual identity centers on the supplied XTC symbol and three
published colors. The [Brand repository](https://github.com/xitcoin-org/brand)
is the source of truth for artwork; this Guide explains how to use it.

## Asset naming

| Context | Required form |
|---|---|
| Canonical native asset | XTC |
| Public asset symbol | XTC |
| Current Cronos contract | `0xE45Fe733bC8617FA6Dac8437Fc44B5ffFA949991` |
| Xitcoin native denomination | XTC (`axtc`) |
| External representations | XTC, identified by network and verified contract, mint or IBC denomination |

An external representation requires verified network metadata and accounting;
a matching logo does not establish that identity.
