# Reference flag assets

This directory contains the 4:3 SVG flag assets displayed in the Sovereign
Participation Reference.

Source: [lipis/flag-icons](https://github.com/lipis/flag-icons)

The files are stored locally so the public guide does not depend on third-party
image delivery. File names use lowercase ISO 3166-1 alpha-2 codes. The images
are presentation assets only and are not authoritative identifiers for
eligibility, legal status, allocation or validator admission.
