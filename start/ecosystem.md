# Ecosystem

The Xitcoin ecosystem is more than the blockchain binary. It includes public services, developer repositories, explorers, community channels and the earlier Cronos XTC ecosystem.

| Component | Purpose | Status source |

## Open-source components

The [xitcoin-org](https://github.com/xitcoin-org) organization hosts the PoS chain, this guide, brand assets, smart contracts, bridge-relayer work and explorer projects.

Repository publication means that work is inspectable. It does not automatically mean every component is deployed or available to users.

## Cronos continuity

XTC's Cronos history remains part of the ecosystem. The guide therefore distinguishes:

* **Cronos XTC:** the current canonical proxy token, identified by its Cronos contract address;
* **native XTC:** the gas and staking asset of the Xitcoin network;
* **external XTC representations:** bridge-backed assets identified by their network and verified contract, mint or IBC denomination;
* **migration history:** prior token-continuity procedures;
* **bridge architecture:** the planned controlled path between networks.

## Operations and stewardship

The four initial core validators are operated by **KCALB Ltd** under distinct validator identities: Atlas, Borealis, Meridian and Zenith. Public code and metadata are maintained through the Xitcoin GitHub organization.
