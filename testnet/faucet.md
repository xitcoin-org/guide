# Get test XTC

Use the [official Xitcoin testnet faucet](https://faucet-testnet.xitcoin.org/) to request test XTC.

1. Connect or enter a testnet address.
2. Confirm the address belongs to the Xitcoin testnet workflow.
3. Submit the request.
4. Verify receipt in the appropriate explorer.

Testnet XTC is free testing material and has no monetary value. Do not purchase it and do not send real assets in exchange for it.
