# Connect a wallet

Xitcoin testnet supports EVM-compatible wallets. Add the network manually only after checking the live [Network status](../start/network-status.md).

| Field | Value |
|---|---|
| Network name | Xitcoin Testnet |
| RPC URL | `https://evm-rpc-testnet.xitcoin.org` |
| Chain ID | `101089` |
| Currency symbol | XTC |
| Explorer | `https://evm-explorer-testnet.xitcoin.org` |

## Safety checks

1. Verify the domain and EVM chain ID.
2. Use a dedicated test wallet.
3. Never import a production seed phrase into an unfamiliar application.
4. Remember that testnet XTC has no monetary value.

If the wallet reports a different chain ID, stop and verify the live endpoint before continuing.
