# Developer overview

Xitcoin supports two complementary interfaces:

* Ethereum-compatible JSON-RPC for Solidity applications and EVM tooling;
* Cosmos RPC, REST and gRPC for native modules, staking and governance.

Use EVM chain ID `101089` for the testnet target and confirm the live Cosmos chain ID before integration testing.
