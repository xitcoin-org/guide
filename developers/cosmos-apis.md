# Cosmos APIs

The public testnet exposes CometBFT RPC and Cosmos REST interfaces.

* RPC: `https://rpc-testnet.xitcoin.org`
* REST: `https://api-testnet.xitcoin.org`

Use these APIs for node information, blocks, transactions, staking, governance and module queries. gRPC consumers should use the published endpoint only after verifying it is active and reachable.
