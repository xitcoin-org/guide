# Responsible disclosure

Security researchers should report vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/xitcoin-org/pos-chain/security).

## Include

* affected component and version;
* reproducible steps;
* expected and observed behavior;
* security impact;
* suggested mitigation, if available.

Do not publish an exploitable issue, secret, private key or sensitive infrastructure detail in a public GitHub issue.

For active theft, key compromise or a threat to consensus safety, stop interacting with the affected service and use a verified Xitcoin communication channel.
